## Overview

A personal portfolio built with the Next.js App Router. The first screen is a pill scene: the red
pill turns the site into a depth mode (engineering, architecture, trade-offs, facts), the blue pill
into a surface mode (visuals first, concise), and scrolling past without choosing gives both. Pages
are rendered statically and revalidated every six hours, so GitHub and LeetCode stats stay fresh
without a backend.

## Highlights

- Mode variants are rendered on the server and switched with CSS, so changing mode causes no layout
  shift and the page works without JavaScript.
- Stats are fetched at build and revalidation time, validated with Zod, and fall back to a
  committed snapshot if an API is unavailable.
- Project pages are written in MDX and generated statically from typed data.
- Unit tests run with Vitest; lint, type checks, formatting and the build run in CI.

## What I learned

Designing for graceful failure first: every external call has a typed fallback, so the site
always renders.
