## Overview

A Node.js script and scheduled GitHub Action that keep a GitHub profile README current.

## Highlights

- Replaces only the content between named markers, so hand-written sections stay untouched.
- Renders LeetCode progress and recently pushed repositories as Markdown.
- Leaves a section unchanged when its data source fails, so the README never breaks.

## What I learned

Idempotent updates and small, pure render functions make scheduled automation easy to test.
