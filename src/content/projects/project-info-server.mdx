## Overview

A small local server that presents project status and artifacts as visual pages: a
bird's-eye view first, with details in stacked modals and hover definitions for every term.

## Highlights

- Content lives in plain JSON files that builders generate, so pages are reproducible.
- A checker validates every page for missing references, legends and glossary terms.
- A visual check captures screenshots so layout regressions are caught before sharing.

## What I learned

Keeping content and code separate makes a tool easy to reuse across projects.
